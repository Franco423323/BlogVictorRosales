Programas para Instalar

Software educativo que se instala y funciona sin necesidad de internet.

Software Educativo

  • Scratch Programación visual para crear juegos e historias interactivas.
  • Tinkercad Diseño 3D y circuitos electrónicos básicos.
  • GeoGebra Matemáticas dinámicas: álgebra, geometría, cálculo y más.
  • Arduino IDE Software para programar placas Arduino en proyectos de electrónica.
  • Stellarium Simulador del cielo estrellado para astronomía.
  • Celestia Explorador espacial en 3D del sistema solar y galaxias.
  • Audacity Editor de audio libre para proyectos de sonido o podcast.
  • GIMP Editor de imágenes similar a Photoshop, de código libre.
  • Blender Modelado y animación 3D para proyectos audiovisuales.
  • LibreOffice Suite ofimática (documentos, hojas de cálculo, presentaciones).
  • Freemind Herramienta para crear mapas mentales.
  • OpenBoard Pizarra digital interactiva para clases presenciales y virtuales.
  • Sweet Home 3D Diseño de interiores en 3D para proyectos de tecnología.
  • CodeBlocks Entorno de programación en C/C++ para nivel avanzado.
  • Notepad++ Editor de texto avanzado para programación y codificación.
  • CamStudio Grabador de pantalla gratuito para hacer tutoriales o presentaciones.
  • OBS Studio Software de grabación y transmisión de video.
  • Recuva Recuperación de archivos eliminados accidentalmente.
  • Foxit PDF Reader Lector y editor básico de archivos PDF.
  • Canva Diseño gráfico para crear presentaciones, infografías, afiches.
